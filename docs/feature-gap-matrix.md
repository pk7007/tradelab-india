# TradeLab India feature gap matrix

Audit date 20 November 2026. Scope is the local checkout based on abc28e7, including changes present before the audit. Scores describe engineering evidence available at inspection. They do not estimate returns, coverage percentages or the probability of reliable operation. A feature may work for a supplied file while its continuous service still needs a provider.

## How to read the scores

Each row gives six separate scores out of ten in this order: completeness, correctness, integration, usability, test coverage and Indian-market suitability. A 2 indicates a prototype or major gap, 5 an implemented subset with material limitations, and 8 a tested workflow with explicit boundaries. A zero indicates no implementation found for that capability. UI scores reflect source inspection. Current runtime verification and news-specific changes belong in the accompanying audit and test report.
